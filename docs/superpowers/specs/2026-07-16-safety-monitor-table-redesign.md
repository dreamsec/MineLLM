# 安全监测全量表格重设计

## 目标

将安全监测分站页面从卡片分组展示改为蓝色科技风数据表格。页面首次进入直接查询
分站 `24080000000043` 的全部传感器，优先满足值班人员快速扫描、检索和对比实时数据
的需求。

## 页面结构

- 顶部使用现有蓝色大屏背景素材，突出分站名称和编码。
- 顶部指标展示传感器总数、当前显示数量、最新监测时间和 30 秒刷新状态。
- 工具栏提供传感器名称/编码关键词搜索、传感器类型筛选和手动刷新。
- 主体使用单一高密度表格，不再按类型拆分卡片。
- 表格列为序号、传感器名称、传感器编码、类型、类别、实时值、单位、状态码和监测时间。

## 视觉方向

- 页面背景使用深蓝色，表头和边框使用亮蓝色，实时值使用高亮青色。
- 表格使用斑马纹、清晰的行悬停反馈和固定表头。
- 类型通过轻量标签区分，不解释 `status_code`。
- 页面不使用装饰性卡片墙、圆形大按钮、湿度占位或无业务含义的图形。
- 小屏幕保留表格最小宽度并允许横向滚动，避免字段挤压和文字重叠。

## 数据与交互

- 页面请求接口时不传 `types`，默认获取全部传感器。
- 类型筛选和关键词搜索在前端本地完成，不额外请求后端。
- 关键词匹配传感器名称、编码和类型，忽略英文大小写并去除首尾空格。
- 保留 30 秒轮询、页面隐藏暂停、旧请求取消和响应乱序保护。
- `value` 为 `null` 时显示 `--`，数值 `0` 正常显示。
- 接口失败时保留上一次成功数据并显示顶部错误提示。

## 验收

- 页面默认全量请求。
- 页面源码和实际布局使用表格，不再渲染 `.sensor-card`。
- 25 条数据能够在固定高度区域滚动查看。
- 关键词和类型筛选可组合使用。
- 安全监测测试、页面契约测试、ESLint 和生产构建通过。
- 不执行 Git 提交。
